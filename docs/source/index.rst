Welcome to MicroPyzzotMet’s documentation!
==========================================

MicroPyzzotMet is a Python library for downscaling meteorological variables
(e.g. temperature, radiation, humidity, precipitation) using DEMs and
reanalysis data such as ERA5-Land, with a focus on snow and mountain applications.
