Main workflow (main_micromet)
=============================

The ``main_micromet`` module contains the high-level entry points that
coordinate the full downscaling workflow based on a configuration file.
It is the programmatic counterpart of running::

    python main_micromet.py config.json

Use this module if you want to call the full pipeline from Python.
